# XingPage

Personal GitHub Page Repo.

1. [Rezepte](https://xingyuxxx.github.io/XingPage/Rezepte/Rezepte.html)
2. [VimCheatSheet](https://xingyuxxx.github.io/XingPage/VimCheatSheet/index.html)

VimCheatSheet uses only Bootstrap 5.3.3 CSS from the jsDelivr CDN for compact tables and an always-visible mode legend, with no local stylesheet. Mixed-mode commands use native Bootstrap cell colors. A small layout script distributes each section's rows across the full available width, using approximately 360 pixels per column and balancing measured row heights. Topics flow consecutively rather than occupying separate grid cards, and topic headings stay with their first command. The layout rebalances when the window is resized and falls back to full-width tables without JavaScript.
